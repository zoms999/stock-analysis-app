# 파트너 대시보드 접근 권한

## 접근 가능한 사용자

파트너 대시보드(`/partner/dashboard`)는 **관리자가 파트너 권한을 부여한 사용자만** 접근할 수 있습니다.

### 파트너 권한 부여 방법

1. **관리자 로그인**
   - `/admin/login`에서 관리자 계정으로 로그인

2. **회원 관리 페이지 이동**
   - `/admin/users` 페이지로 이동

3. **파트너 권한 부여**
   - 파트너 권한을 부여할 사용자를 찾습니다
   - 해당 사용자의 "파트너" 버튼을 클릭하여 파트너 권한을 활성화합니다
   - `is_partner = true`로 설정됩니다

### 파트너 권한 확인

파트너 권한이 있는 사용자는:
- `profiles` 테이블의 `is_partner` 컬럼이 `true`로 설정되어 있습니다
- `/partner/dashboard`에 접근할 수 있습니다
- 추천인 링크를 통해 가입한 사용자의 결제에 대해 커미션을 받을 수 있습니다

### 일반 사용자 접근 시도

일반 사용자(`is_partner = false`)가 파트너 페이지에 접근하려고 하면:
- 접근이 거부됩니다
- "파트너 전용 페이지입니다" 알림이 표시됩니다
- 홈페이지(`/`)로 리다이렉트됩니다

### 파트너 기능

파트너는 다음 기능을 사용할 수 있습니다:

1. **대시보드** (`/partner/dashboard`)
   - 추천한 사용자 수
   - 총 정산 완료 금액
   - 정산 대기 금액
   - 추천인 링크 생성 및 공유

2. **정산 내역** (`/partner/settlements`)
   - 과거 정산 내역 조회
   - 정산 상태 확인

3. **정산 요청** (`/partner/request-settlement`)
   - 정산 대기 금액을 실제로 정산 요청
   - 정산 완료 후 포인트로 지급

### 기술적 구현

- **접근 제어**: `src/app/partner/layout.tsx`에서 `is_partner` 플래그 확인
- **데이터베이스**: `profiles.is_partner` 컬럼 사용
- **RLS 정책**: 파트너 관련 데이터는 RLS로 보호됨

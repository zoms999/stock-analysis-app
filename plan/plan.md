1. 서비스 개요
1.1. 서비스명
(가칭) 차트 기반 투자 커뮤니티 & 리워드 플랫폼
1.2. 기획 목적
외부 금융 데이터와 커뮤니티의 결합: 사용자가 주식/코인 등 외부 차트 데이터를 직접 불러와 분석글을 작성하고 공유하는 환경 제공.
구독형 멤버십(SaaS) 도입: 등급별 게시판 열람 및 작성 권한을 차등 부여하여 수익 모델 구축.
바이럴 마케팅 & 수익 공유: SNS 공유를 통한 토너먼트 참여 유도 및 인플루언서 파트너 수익 쉐어 모델 도입.
1.3. 타겟 유저
주식/코인 투자자 및 차트 분석가.
고급 투자 정보가 필요한 일반 개인 투자자.
커뮤니티 활동 및 팔로워를 통해 수익을 창출하려는 인플루언서.

2. 주요 기능 및 프로세스
2.1. 회원 및 인증
회원가입: 이메일/비밀번호 기반 일반 가입 및 소셜 로그인(구글, 페이스북, 자체 가입) 지원.
다국어 지원: 글로벌 확장을 위한 언어팩 적용 (한국어, 영어 30~50개 등).
레벨 시스템: 활동 및 구독 여부에 따라 1~10등급으로 구분하여 권한 관리.
2.2. 게시판 및 차트 (Core Feature)
외부 API 연동: 주식, 코인 등 1~3곳의 외부 시세 정보를 연동하여 게시글 내 실시간/과거 차트 삽입.
글쓰기 에디터: 텍스트 작성 및 차트 데이터 불러오기 기능 통합.
열람 제한 (Point Deduction):
게시글 열람 시 사용자의 '열람 횟수' 또는 '포인트'가 차감됨.
SNS 공유 혜택: 게시글 SNS 공유 시 게시판 열람 권한 획득 또는 포인트 보상 지급.
2.3. 구독 및 결제

2.4. 관리자 및 포인트 정책
포인트 지급 관리:
자동 지급: 시스템 설정 조건(예: 글 작성, 댓글 수 달성) 충족 시 즉시 지급.
수동 지급: 사용자가 포인트 요청 시 관리자가 내역 검수 후 승인 처리.
포인트 회수: 게시판 열람 시 시스템에서 자동 차감.
2.5. 파트너 수익쉐어 (마케팅)
서브도메인 제공: 파트너 식별을 위한 추천 URL 접속 주소 제공.
추천코드 자동 적용: 파트너 링크를 통해 접속 및 가입 시 추천인 코드 자동 입력.
수익 정산: 파트너 회원을 통해 발생한 매출(구독료 등)의 일정 비율을 파트너에게 쉐어.
2.6. 토너먼트 이벤트 (Viral Logic)
상품 지급: 이벤트 토너먼트 최종 승자에게 리워드/상품 지급.
패자 부활(Re-entry) 로직:
참여 중 탈락 시 SNS 공유(보유 포인트 사용)를 수행하면 재참여 기회 부여.
공유 완료 시 참여 가능 슬롯(기회)이 3곳으로 증가.(관리자 참여 기회 포인트 설정)
결승까지 지속적인 참여를 유도하여 SNS 확산 효과 극대화.
승자 관리: 토너먼트 우승자 및 입상자 데이터 별도 관리 및 명예의 전당 노출.
이벤트 종류            
                1 코스피 소수점 뒤 2자리 맞추기 (증시 api 자동 정산 승자 분류됨)
                2  삼성 전자 다음주 월~금 주가 예측 정확도 3위까지 진출


3. UI/UX 구성
3.1. 메인 및 상세 화면 레이아웃
헤더(Header): 통합 검색창(단축키 Ctrl+K), 다국어 변경 버튼, 로그인/마이페이지.
상단 정보: 현재 접속 기준 년/월/일/시/분 표시.
차트 영역 (Main):
비트코인(BTC) 등 사용자가 선택한 종목의 실시간 Price Chart 시각화.
[Save Point] 버튼: 차트 영역 내 배치, 클릭 시 현재 시점 데이터 캡처 또는 포인트 적립 액션 수행.
컨텐츠 영역:
차트 하단에 [본문 내용 글쓰기] 영역 배치.
차트를 보며 즉각적인 분석 및 코멘트 작성이 가능한 UI 구조.
